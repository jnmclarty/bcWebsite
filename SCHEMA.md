# Database Schema

Postgres schema for the bcWebsite CMS. Tables are generated by Payload CMS v3 from the collection configs in `src/collections/*.ts` — there is no hand-written Drizzle schema. All tables live in the `public` schema. Every table has an integer `id` primary key (unless noted) and most have `created_at` / `updated_at` timestamps (`timestamp with time zone`, default `now()`).
